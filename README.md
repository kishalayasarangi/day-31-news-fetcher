# Day 31 — News Headline Fetcher

**120 Days of Code** | NIT Rourkela | Mechanical Engineering

## What this is
A news headline fetcher that pulls live headlines
from multiple categories using a free news API.

## How to view
Open `index.html` in your browser.

## Features
- Live headlines from GNews API
- Filter by category: Tech, Sports, Science, Business
- Search news by keyword
- Click to read full article
- Clean card layout
